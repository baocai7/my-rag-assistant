# 截图目录

README 里引用了这 5 张图，请按下面的文件名放入：

| 文件名 | 拍什么 | 为什么重要 |
|---|---|---|
| `01-chat.png` | 💬 对话 Tab，连着问两个问题形成多轮 | 展示流式输出 + 上下文 |
| `02-rag-citation.png` | 📚 文档问答，答案里带 `[文件名 p.页码]` 高亮 | 展示引用溯源 |
| `03-sources.png` | 同一次回答，展开「查看 N 个检索片段」 | 展示相似度分数 |
| `04-fallback.png` | 问一个文档里没有的问题，出现 🟡「来自模型自身知识」 | **最有价值**：证明检索路由生效 |
| `05-eval.png` | 终端里 `python eval_rag.py -k 4` 的输出 | 展示量化评估结果 |

## 拍图建议

- 浏览器窗口拉宽到 **≥1200px**，避免内容挤压
- ⚠️ **不要拍入服务器地址 / 实例 ID**（如果用了云 GPU，URL 里可能带实例标识）
- macOS 用 `Cmd+Shift+4` 框选，避免截入浏览器书签栏和地址栏
